## What is ALFRED?

ALFRED combines:

1. On-chain **DID registry** + per-holder **VC vaults** (Soroban).  
2. Human onboarding via **Pollar** (social login → embedded wallet).  
3. An Apple-like bilingual app on **Cloudflare Pages / Workers**.  
4. These docs on **GitBook** (source: `docs/gitbook/` in the repo).

On-chain: identifiers, status, and **hashes**. Off-chain: encrypted claims.
